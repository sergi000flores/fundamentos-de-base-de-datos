– Normalización de Base de Datos

Descripción

Esta tarea consiste en realizar el proceso de normalización de una base de datos para una clínica veterinaria, aplicando la Primera, Segunda y Tercera Forma Normal (1FN, 2FN y 3FN), además de verificar el cumplimiento de la Forma Normal de Boyce-Codd (FNBC).

Objetivo

Eliminar la redundancia de datos, evitar dependencias innecesarias y mejorar la integridad de la información.
